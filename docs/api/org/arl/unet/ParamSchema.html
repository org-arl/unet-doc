Package: org.arl.unet

[Java] Annotation Type ParamSchema

    • org.arl.unet.ParamSchema

    • Schema metadata for a org.arl.fjage.param.Parameter enum constant, intended to be consumed by schema-extraction tooling (e.g. to generate JSON schemas, TypeScript types or parameter editors).

      The type attribute uses string type tokens with the following grammar:

      • scalars: byte, int, long, float, double, boolean, String, AgentID, Date. Types are JSON-equivalent; a boxed primitive is not distinguished from its primitive (write int, not Integer).
      • arrays (homogeneous sequences): append [], e.g. float[], String[], Complex[].
      • maps/dictionaries: Map or Map<Key,Value>, e.g. Map<String,float>. The value type may be approximate for agent-defined maps.
      The type is the return type of the parameter's getter. A setter, if the parameter is writable, must accept a value of this type, but may additionally accept other types and conversions (e.g. a string "auto", or an AgentID in place of a name); such extra write types are documented in the constant's own Javadoc and the relevant shell extension help, not here. Whether a parameter is read-only is determined at runtime from the presence of a setter and is likewise not recorded here.

      optional and nullable are different service contracts. A nullable parameter must be implemented by the agent, but its getter may return null; in a response to a org.arl.fjage.param.ParameterReq for all parameters it is listed with a null value, advertising that setting it may enable some functionality. An optional parameter may be left unimplemented by an agent (e.g. when it relates to a capability that is unavailable); it is then omitted entirely from such a response, keeping the parameter list uncluttered.
