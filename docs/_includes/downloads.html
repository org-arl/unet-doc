Download started

unet-community-{{ version }}.tgz · 20.9 MB

Unpack it and start a simulated 2-node network:

tar xzf unet-community-{{ version }}.tgz
cd unet-{{ version }}
bin/unet samples/2-node-network.groovy

The simulation prints a web URL for each node — open them to get a command shell.
